# Netflix Clone

A responsive Netflix page clone built using HTML and CSS.

## 🛠️ Tech Stack

**HTML5:** Used semantic HTML tags to make the structure more accessible, organized, and easier to style.

**CSS3:** Used Flexbox, CSS Grid, transitions, animations, and media queries to create a responsive layout.

## 📱 Features

* **Button Hover Effects:** Buttons glow on hover using CSS transitions and animations.
* **Number Overlay:** Added numbered overlays on movie posters.

## 📈 Challenges & What I Learned

**Challenges:**
I faced several challenges while building this project, especially while creating the numbered overlays on the posters and designing the language selector similar to Netflix. For the language selector, I had to remove the default button appearance, align the language icon, text, and arrow in a single line, and then style them as one complete button with a focus state.

**What I Learned:**
Through this project, I learned how to create overlays using CSS and build a more complex language selector. I also improved my understanding of Flexbox, CSS Grid, media queries, transitions, and animations.
